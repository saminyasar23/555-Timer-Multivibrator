# 555 Timer Multivibrator
 555 Timer Multivibrator Circuits  This repository contains Proteus simulations of three fundamental 555 timer configurations: **astable, monostable, and bistable multivibrators**. The designs demonstrate how a 555 timer can be used to generate clock pulses, produce a timed output, and operate as a memory or switching circuit.  ### Included Designs  - 
 **Astable Multivibrator:** Generates a continuous square-wave signal without requiring an external trigger. The output waveform and capacitor charging/discharging process are observed using a virtual oscilloscope. - 
 **Monostable Multivibrator:** Produces a single output pulse for a predetermined duration whenever an input trigger is applied. The timing interval is controlled by the resistor-capacitor network. - 
 **Bistable Multivibrator:** Operates as a two-state memory circuit. The output changes state when the set or reset push button is pressed and remains in that state until the opposite control is activated.  The simulations include a 555 timer IC, timing resistors and capacitors, push-button controls, LEDs, and an oscilloscope for monitoring the output signals. These circuits provide practical demonstrations of timing, pulse generation, switching, and basic memory functions in digital electronics.
